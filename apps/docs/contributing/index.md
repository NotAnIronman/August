# Contributor policies

These pages define how August stays navigable with explicit application, package, tool,
and data ownership.

- [Repository layout](repository-layout.md): target tree, dependency boundaries, and
  compatibility markers
- [Naming standard](naming.md): paths, files, identifiers, branches, and safe renames
- [Testing policy](testing.md): validation levels, test placement, and manual records
- [Data and generated artifacts](generated-data.md): classifications, provenance, and
  generator rules
- [Experiments](experiments.md): approved temporary locations and exit criteria
- [Environment and migrations](environment-and-migrations.md): secrets, mutable state,
  and safe data changes

The repository-root **CONTRIBUTING.md** is the operational checklist.
